## Required Software Installations
All installations in this section are one-time only. If not already installed, download and install the following software.

|Software|Link|Notes|
|---|---|---|
|Python|https://www.python.org/downloads|This project uses Python v13.2.|
|VS Code|https://code.visualstudio.com/download||
|Git|https://git-scm.com/install/windows||

The following software can be installed via a Powershell terminal by running the associated commands.

|Software|Command|
|---|---|
|`uv`|`powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 \| iex"`|
|`just`|`winget install --id Casey.Just -e`|
|GitHub CLI |`winget install --id GitHub.cli`|

See [Installation](docs/installation.md) for further installation and setup instructions.
